# PinFlow Compatibility Map

PinFlow package identity is now canonical. The remaining compatibility window goes in the other direction:

- Preferred package names are `@pinflow/*`
- Preferred binaries are `pinflow` and `pinflow-mcp`
- Legacy `@pinflow/*` references remain available only as transitional compatibility aliases while downstream integrations migrate

The active canonical surfaces are:

- `@pinflow/core`
- `@pinflow/react`
- `@pinflow/vue`
- `@pinflow/next`
- `@pinflow/nuxt`
- `@pinflow/transform`
- `@pinflow/runtime`
- `@pinflow/manifest`
- `@pinflow/overlay`
- `@pinflow/relay`
- `@pinflow/mcp`
- `pinflow`

This directory documents the migration state until the remaining deep compatibility layers are fully retired.
