# Changelog

## 0.6.0-pinflow.0

Initial PinFlow public release candidate.

- Renamed and productized the Domscribe foundation as PinFlow.
- Added German README, PinFlow visual assets, local setup explanation, and
  comparison tables.
- Added `pinflow init` onboarding for agent and frontend setup.
- Added Codex, Claude, Gemini, Kiro, Cursor, and generic MCP onboarding paths.
- Added React, Vue, Next.js, Nuxt, Vite, Webpack, and Turbopack package
  coverage.
- Added local relay, annotation queue, MCP tools, and provider-aware dispatch
  flows.
- Added release checks, npm-public package metadata, release guide, and security
  notes.
