# PinFlow CLI

Preferred command-line entrypoint for PinFlow, with `domscribe` kept as a compatibility alias.

## Install

```bash
npm install -g pinflow
```

Then use either:

```bash
pinflow
```

or the compatibility alias:

```bash
domscribe
```

## Note

Starts the relay server and MCP adapter from the command line.

Compatibility note: `domscribe` remains available as a temporary alias during the migration window.

## Links

PinFlow is built from the original [Domscribe](https://github.com/patchorbit/domscribe) foundation.
