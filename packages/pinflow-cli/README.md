# PinFlow CLI

Preferred command-line entrypoint for PinFlow, with `pinflow` kept as a compatibility alias.

## Install

```bash
npm install -g pinflow
```

Then use either:

```bash
pinflow
```

or the compatibility alias:

```bash
pinflow
```

## Note

Starts the relay server and MCP adapter from the command line.

Compatibility note: `pinflow` remains available as a temporary alias during the migration window.
